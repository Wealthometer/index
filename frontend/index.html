How this demo is wired

  1. Frontend: plain HTML/CSS/JS — index.html, style.css, app.js. No build step, no framework.
  2. Backend: the Express + MongoDB API you uploaded (authRoutes, productRoutes, orderRoutes).
  3. Connection: app.js calls API_BASE (default http://localhost:5000/api). Change that one constant to point anywhere.
  4. Fallback: if /api/health doesn't respond, the site switches to local mock data automatically — same UI code path either way.
  5. Auth: login/register store the returned JWT in localStorage; the order request sends it back as Authorization: Bearer <token>.

Run the API with npm install && npm run dev (needs a MONGO_URI in .env), then reload this page — the badge in the navbar will flip to "Live API".
